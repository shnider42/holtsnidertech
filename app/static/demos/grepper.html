The eventual live-demo model is straightforward.

Keep collection server-side on a schedule, write the normalized jobs to one cached snapshot, and let this public page read only that file. In other words: the browser never scrapes Workday. A scheduled importer replaces grepper-snapshot.json, and the comparison UI stays exactly the same.

Grepper is a Holtsnider Tech prototype and is not affiliated with or endorsed by Workday. Workday is referenced here only to explain the workflow Grepper is designed to improve. This demo snapshot contains representative generated records rather than current third-party job listings.
